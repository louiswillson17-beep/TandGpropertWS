# T&G Property Management & Landscaping

Complete static website package for T&G Property Management & Landscaping.

## Included
- `index.html` — complete website with embedded styling and scripts.
- `README.md` — deployment and editing notes.

## Technologies
The website is built with standard HTML5, CSS3, and vanilla JavaScript. No build step or framework is required.

## External resources
The page uses remote web fonts and image resources referenced from the HTML. An internet connection is recommended for the complete visual experience.

## Run locally
Open `index.html` directly in a modern browser, or serve the folder with any simple static web server.

Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment
Upload the contents of this folder to any static hosting provider or web server. `index.html` is the entry page.
